# AyurNeuro 🧠🌿

### The Multi-Framework Neuro-Ayurvedic Diagnostic Platform

AyurNeuro is an AI-powered medical imaging platform that analyzes brain MRI scans using TensorFlow and PyTorch models for accurate tumor detection. The platform integrates Gemini AI and LangChain to generate personalized Ayurvedic recovery recommendations, combining modern Deep Learning with holistic healthcare approaches.

## 🚀 Features

* 🧠 Brain Tumor Detection using Deep Learning
* ⚡ Dual-Framework Verification (TensorFlow + PyTorch)
* 🔍 Explainable AI Heatmaps & Feature Visualization
* 🌿 AI-Generated Ayurvedic Recovery Suggestions
* ☁️ Firebase Cloud Storage for Patient History
* 💬 Gemini AI + LangChain Integration
* 🎨 Interactive Streamlit Dashboard UI

## 🛠️ Tech Stack

* **Frontend:** Streamlit
* **Deep Learning:** TensorFlow, PyTorch
* **Generative AI:** Gemini 2.5 Flash
* **Orchestration:** LangChain
* **Database:** Firebase Firestore
* **Visualization:** Pillow, ImageOps
